# DRS Spectra Decomposition: Absorption and Scattering Separation

Программный комплекс для автоматического разделения компонент поглощения (μₐ) и рассеяния (μₛ) в спектрах диффузного отражения (DRS) с использованием гибридного подхода, сочетающего классический MCR-ALS анализ и современные нейросетевые методы.

## Ключевые особенности
- **Высокая скорость обработки**: <1 секунды на спектр (в 100–1000 раз быстрее традиционных методов)
- **Гибридная архитектура**: объединение точности CNN и скорости оптимизированных алгоритмов
- **Автоматическая генерация данных**: создание синтетических спектров для обучения модели
- **Статистическая валидация**: оценка качества через критерии Мана-Уитни и Колмогорова-Смирнова с FDR-коррекцией
- **Гарантия неотрицательных значений**: для всех физически значимых параметров

## Структура проекта

### 1. Основной модуль: `CNN.py`
**Гибридная модель CNN для предсказания μₐ и μₛ**

Модель объединяет лучшие компоненты двух подходов:
- **Архитектура**: остаточные блоки с depthwise-свертками для ускорения
- **Механизм внимания**: Efficient Spectral Attention для выделения значимых спектральных областей
- **Функция потерь**: адаптивная комбинация MSE, MAE и Huber loss
- **Обучение**: mixed precision training, cosine annealing, early stopping
- **Вход**: 591 канал (9000–4450 см⁻¹)
- **Выход**: коэффициенты поглощения (μₐ) и рассеяния (μₛ)

**Ключевые улучшения:**
- Использование синтетических и экспериментальных данных
- Умная аугментация спектров
- Оптимизация для работы на GPU

### 2. Генератор синтетических данных: `Data_synth.py`
**Создание калиброванных синтетических спектров**

Решает проблему недостатка экспериментальных данных:
- **Фиксированный формат**: 591 канал, длины волн 9000–4450 см⁻¹
- **Калибровка**: соответствие экспериментальным распределениям
- **Гарантии**: неотрицательные значения, уникальность спектров
- **Конфигурации**: Air, Sp10, Sp40, Sp80, Sp100, TransPE
- **Статистическая оценка**: тесты Мана-Уитни и Колмогорова-Смирнова с FDR-коррекцией Бенджамини-Хохберга

### 3. Классический метод: `MCR-ALS.py`
**Multivariate Curve Resolution - Alternating Least Squares**

Реализация классического подхода для:
- **Разложение спектров**: на компоненты поглощения, рассеяния и пропускания
- **Создание эталонов**: чистые спектры для обучения CNN
- **Валидация**: сравнение с нейросетевым методом
- **Выходные файлы**: 
  - `pure_spectra_test.xlsx` — чистые спектры компонентов
  - `computed_Absorb_test.xlsx` — концентрации поглощения
  - `computed_Scatt_test.xlsx` — концентрации рассеяния
  - `computed_Trans_test.xlsx` — концентрации пропускания

### Запуск полного пайплайна
1. **Подготовка данных**: запустите `MCR-ALS.py` для получения чистых спектров
